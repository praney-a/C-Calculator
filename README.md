# C Calculator

A simple calculator program developed using C as part of my programming practice.

## Features
- Performs basic arithmetic operations
- Takes user input
- Displays the calculated result

## Tech Stack
- Language: C
- Editor: Visual Studio Code
- Compiler: GCC

## How to Run
Compile the program using:

```bash
gcc calculator.c -o calculator
```

Run it on Windows:

```bash
.\calculator.exe
```

## Learning Outcome
This project helped me practise C programming, user input, operators, and conditional statements.
